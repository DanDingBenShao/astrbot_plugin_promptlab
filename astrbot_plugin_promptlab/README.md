# astrbot_plugin_promptlab

PromptLab 双AI对抗训练室：你提需求，一个 AI 改提示词（优化师），另一个 AI 验收效果（验收官）。

## 它解决什么问题

你让 bot「回复更像真人」，它口头答应「好的」，实际回复还是老样子；或者你自己改了提示词，改没改到位只能靠肉眼一遍遍试——又累又不客观。

PromptLab 的答案是**基线对照 + 逐项验收**：

1. **基线**：先用 bot 当前提示词产一份「基线回复」留底
2. **清单**：验收官把你的需求拆成 3-6 条可检查项（「句尾无句号」「不用书面衔接词」，不是「更像人」）
3. **对抗**：优化师改提示词 → 被训者用新提示词产回复 → 验收官逐项打分。与基线几乎没差？直接判不过——敷衍混不过去
4. **必停**：通过或满轮（默认 3 轮）必停，交付报告 + 收敛后的提示词全文，你自己决定贴不贴回 bot

全程离线：迭代的是**候选提示词**，不碰 bot 正在用的人设，零生产风险。

## 指令

| 指令 | 作用 |
|---|---|
| `/训练开始 <需求>` | 开一次训练 |
| `/训练状态` | 看进度（清单/末轮评分） |
| `/训练停` | 本轮结束后停下（不硬杀） |
| `/训练报告` | 完整报告 + 收敛提示词 |
| `/训练继续 [N]` | 继续/加 N 轮 |
| `/训练样本 <文本>` | 手动给风格样本（可选） |
| `/训练语料 <路径>` | 语料包文件（JSON/JSONL/TXT），按需求自动清洗+挑选样本 |
| `/训练语料 预览 <需求>` | 先看挑选效果再开训 |
| `/训练列表` | 历史训练 |

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| `max_rounds` | 3 | 对抗轮次上限（满轮必停），1-10 |
| `pass_score` | 70 | 及格线（0-100） |
| `prompt_model` | 空 | 优化师模型（空=主模型） |
| `judge_model` | 空 | 验收官模型（建议与被训 bot 不同模型，防自评偏袒） |
| `act_model` | 空 | 被训者模型（应等于被训 bot 的主模型） |
| `samples_limit` | 20 | 从官方会话历史取风格样本条数（0=不取） |
| `samples_chars` | 1200 | 风格样本总字数上限 |

## 成本

一次 3 轮训练 ≈ 1 次清单 + 1 次基线 + 3×(优化师+被训+验收) = **11 次调用**，全部走 AstrBot 当前配置的模型，无隐藏开销。

## 语料包（v0.2.0）

`/训练语料 <文件绝对路径>` 登记一个语料包（设一次，后续训练都用它）：

- **格式自动识别**：JSON `list[{nick,text}]`（qqmind 画像语料）/ `list[{role,content}]` / JSONL / 纯文本（一行一条）
- **自动清洗**：命令、`[图片]`/`[At:xxx]`/`[表情:xx]` 组件、链接、纯标点、超长刷屏全部剔除
- **按需求挑选**：需求里的风格词（短/口语/梗/句尾/情绪…）命中消息文本的优先，短/中/长三档均衡取样，带轻微随机抖动（同批不重样）
- **零 token**：挑选全部本地规则完成，不花模型调用；`/训练语料 预览 <需求>` 可先看挑选效果

样本优先级：`/训练样本` 手动文本 > 语料包挑选 > 会话历史（官方 `get_conversations`）。

## 兼容性

- 不注册任何 LLM 钩子，不碰 `req.contexts` / `system_prompt`，与其他插件零干扰
- 会话历史只读官方 `get_db().get_conversations()`；不依赖任何其他插件（qqmind 装不装都行）
- 数据在 `data/plugin_data/astrbot_plugin_promptlab/`，删除即卸载
